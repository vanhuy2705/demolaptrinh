== HUONG DAN KET NOI SQL SERVER ==

Mo file: appsettings.json
Thay dong "DefaultConnection" bang 1 trong 2 mau sau:

----------------------------------------------------------------------
[1] Windows Authentication (dang nhap bang tai khoan Windows):
----------------------------------------------------------------------
"DefaultConnection": "Data Source=TEN_SERVER;Initial Catalog=QLSanTheThao;Integrated Security=True;TrustServerCertificate=True;MultipleActiveResultSets=True"

Vi du cu the:
  - SQL Server cuc bo, instance mac dinh:
    Data Source=.;...
  - SQL Server cuc bo, instance SQLEXPRESS:
    Data Source=.\SQLEXPRESS;...
  - SQL Server tren may khac:
    Data Source=192.168.1.10;...

----------------------------------------------------------------------
[2] SQL Server Authentication (dang nhap bang user/password SQL):
----------------------------------------------------------------------
"DefaultConnection": "Data Source=TEN_SERVER\TEN_INSTANCE;Initial Catalog=QLSanTheThao;User ID=TEN_DANG_NHAP;Password=MAT_KHAU;TrustServerCertificate=True;MultipleActiveResultSets=True"

Vi du (dung sa, cung may, instance mac dinh):
  Data Source=.;Initial Catalog=QLSanTheThao;User ID=sa;Password=YourPassword123;TrustServerCertificate=True;MultipleActiveResultSets=True

----------------------------------------------------------------------
CAC GIA TRI CAN THAY:
----------------------------------------------------------------------
  TEN_SERVER      -> ten may chu (dung "." neu cung may)
  TEN_INSTANCE    -> ten instance SQL (thuong SQLEXPRESS hoac MSSQLSERVER)
  TEN_DANG_NHAP   -> tai khoan SQL (thuong la sa)
  MAT_KHAU        -> mat khau tuong ung
  QLSanTheThao    -> ten database (giu nguyen, da khop voi script SQL)

----------------------------------------------------------------------
SAU KHI DIEN XONG:
----------------------------------------------------------------------
1. Dam bao appsettings.json chi co JSON thuan, khong co comment /*...*/
2. Chay 01_TaoCSDL.sql tren SSMS de tao database
3. Chay 02_DuLieuMau.sql tren SSMS de nhap du lieu mau
4. Khoi dong ung dung
